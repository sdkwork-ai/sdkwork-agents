# en-US locale seeds

- `001_agent_catalog_display.sql` — English display names, descriptions,
  management profiles, system prompts, and skill instructions for the official
  agent catalog.
- `002_expert_catalog.sql` — English display names, descriptions and persona
  bodies for the 331 expert agents, plus the `ai_expert_persona` rows.

The language-neutral identities and references live in
`seeds/common/002_agent_catalog.sql` and `seeds/common/003_expert_catalog.sql`.
`001_agent_catalog_display.sql` is generated by
`scripts/generate-agent-catalog-seeds.mjs`; `002_expert_catalog.sql` by
`scripts/generate-expert-seeds.mjs`. Do not hand-edit.
