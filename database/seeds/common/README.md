# Common seed scripts

Locale-agnostic seed SQL referenced from `seeds/seed.manifest.json` profiles.

- `001_bootstrap.sql` — deterministic standard-profile marker.
- `002_agent_catalog.sql` — official 58-agent catalog neutral base: ids, codes,
  taxonomy, version snapshots, composition slots, and capability references.
  Display names, descriptions, system prompts, and skill instructions are
  intentionally unset here and supplied by the locale seeds.

Generated by `scripts/generate-agent-catalog-seeds.mjs`. Do not hand-edit.
